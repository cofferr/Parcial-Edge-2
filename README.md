# edge-parcial

Parcial práctico de Edge Computing, Parte 1: caracterización empírica de latencia y ancho de banda
de tres fuentes de video (cámara local, ESP32-CAM, DroidCam).

- Diseño y decisiones: `docs/DISENO.md`
- Fórmulas y archivos que las calculan: `docs/matriz_formulas.md`
- Configuración: copiar `config/config.example.toml` a `config/config.toml`
- Pruebas: `uv run pytest` y `uv run ruff check .`
- Verificación manual del lector con hardware: `docs/verificacion_lector.md`
- Checklist de medición con hardware (en orden): `docs/CHECKLIST_HARDWARE.md`
- Decisiones tomadas de forma autónoma (para revisar): `docs/DECISIONES_AUTONOMAS.md`
